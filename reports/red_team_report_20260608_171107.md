# 🔴 INFORME EJECUTIVO: FEEDBACK LOOP ATTACK SIMULATION

## Resumen Ejecutivo

Se ejecutó una campaña de Red Team contra la API de Machine Learning defensivo utilizando un esquema **GAN-like (Macro-GAN Semántica)** como Generator. El objetivo era evadir el discriminador (modelo de seguridad) mediante mutaciones iterativas de payloads maliciosos.

## Metodología

| Fase | Descripción |
|------|-------------|
| **Round 0** | Envío de payloads base sin mutación |
| **Round 1** | Aplicación de técnicas: encoding, comentarios inline, double encoding, base64 |
| **Round 2** | Técnicas: hex encoding, protocol manipulation, tab/newline encoding |
| **Round 3** | Técnicas avanzadas: MySQL comment tricks, stacked mutations |
