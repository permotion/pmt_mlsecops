## 🎯 Payloads que Evadieron el Modelo (Falsos Negativos)

### **1. SQL Injection - Stacked Query with xp_cmdshell**
```
';EXEC xp_cmdshell('dir');--
```
- **Confidence:** 0.34 (BAJA - no detectó la amenaza)
- **Razón de evasión:** El modelo parece no estar entrenado para detectar stacked queries con procedimientos almacenados extendidos (`xp_cmdshell`).
- **Impacto:** Permite ejecución remota de comandos en el servidor de base de datos.

### **2. XSS - JavaScript Protocol URI**
```
javascript:alert(document.domain)
```
- **Confidence:** 0.31 (BAJA - no detectó la amenaza)
- **Razón de evasión:** El modelo solo detecta tags HTML y eventos inline, pero no reconoce el protocolo `javascript:` en URIs.
- **Impacto:** Permite ejecución de JavaScript arbitrario en el contexto del navegador.

---

## 📋 Vulnerabilidades Identificadas en el Modelo

### Debilidades del Discriminator (Modelo Defensivo):

1. **No detecta stacked queries SQL** - El modelo no identifica múltiples statements SQL separados por `;`
2. **Procedimientos almacenados extendidos** - No tiene signatures para `xp_cmdshell`, `sp_executesql`, etc.
3. **Protocolos URI especiales** - No detecta `javascript:`, `vbscript:`, `data:` en contextos de XSS
4. **Obfuscación de alto nivel** - Null bytes y codificación múltiple no siempre son detectados

---

## 🔄 Recomendaciones de Hardening para el Discriminator

1. **Ampliar dataset de entrenamiento** con muestras de stacked queries SQL
2. **Agregar features** para detectar procedimientos almacenados extendidos
3. **Implementar análisis semántico** más allá de pattern matching
4. **Detectar protocolos URI** como `javascript:`, `data:`, `vbscript:`
5. **Considerar contexto** (atributos href, src vs contenido de tags)

## ✅ Conclusión

El modelo de ML actual es efectivo contra ataques SQLi y XSS **clásicos**, pero presenta **gaps significativos** ante técnicas avanzadas de evasión. Se recomienda re-entrenar el modelo con los payloads evasores descubiertos como ejemplos de ataque para mejorar la detección de falsos negativos.
