## 5. Recomendaciones de Mitigación

### Para el Equipo de Seguridad:

1. **Implementar Hex Decoding en Preprocessing:**
   ```python
   # Antes del pattern matching
   if payload.startswith('0x'):
       payload = bytes.fromhex(payload[2:]).decode('utf-8', errors='ignore')
   ```

2. **Detectar SVG Tags y Event Handlers:**
   - Incluir patrones para `<svg`, `onload`, `onerror` en listas de bloqueo
   - Implementar sanitización de SVG

3. **Detectar String.fromCharCode:**
   - Crear pattern específico para esta técnica de ofuscación
   - Considerar sanitización de cualquier uso de `eval()` o `Function()`

4. **Defensa en Profundidad:**
   - Combinar pattern matching con análisis semántico
   - Implementar WAF adicional capa de red
   - Logging exhaustivo de rechazos
